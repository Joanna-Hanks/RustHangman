# Rust Hangman Game

This project is a simple command-line Hangman game written in Rust. The player chooses a hidden word and attempts to guess it one letter at a time. The game keeps track of guessed letters and incorrect guesses and allows the player to play multiple games.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install Rust and Cargo on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal and run `cargo build` to build the project.
4. Run `cargo run` to start the Hangman game.

Instructions for using the software:

1. Choose a word number from 1 to 5 when prompted.
2. Enter one letter at a time to try to guess the hidden word.
3. Continue guessing letters until you guess the word or use all 6 incorrect guesses.
4. Choose whether you want to play another game when prompted.
